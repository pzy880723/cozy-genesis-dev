## 素材库 UI 调整

仅改 `src/routes/_authenticated/assets.tsx`，不动数据/接口。

### 1. 缩略图强制正方形
- 卡片图片容器保持 `aspect-square` + `object-cover`（已是正方形，但确认在网格收窄时不被拉伸；视频/文案/分镜等也统一 `aspect-square`）。
- 列表视图不变。

### 2. 分类栏从左侧移到顶部（搜索条下方）
- 删除左侧 180px Panel 分类列。
- 在搜索/筛选条**下方**新增一行横向分类 chips：`全部 / 图片 / 视频 / 文案 / 分镜 / 角色 / 产品`，每个 chip 右上角带小数字徽标，激活态用 `bg-primary-soft text-primary`。
- 主体改为单列，素材网格直接撑满。

### 3. 去掉重复标题
- 删掉素材 Panel 的 `title="素材"`（页面顶部 PageHeader 已有"素材库"）。
- 把"共 N 个"计数移到分类 chips 行右侧，保持信息可见。

### 不变项
- 来源角标、放大/发布悬浮入口、预览弹窗、标签管理弹窗、分页"加载更多"、所有筛选逻辑与 query key。
