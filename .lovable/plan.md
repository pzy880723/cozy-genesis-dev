# 3 套 Dense Operator 设计稿 · 出图方案

设计直接渲染要么需要"当前预览截图"（被登录拦截 + 我现在是 plan 模式），要么直接在项目里写 HTML 原型（plan 模式禁止写文件）。所以把 3 套方向的**骨架**先在这里讲清楚，你确认后我切到 build 模式**直接出 3 张高保真 PNG 大图**（1600×1200，每张含入口 / 步骤流程 / 结果三块完整布局），你选一套，我再做全站套用。

锁定参数（三套都不动）：
- 配色 Charcoal & Ember + 暖白底 `#faf8f5`，主色 ember `#e85d3a`
- 标题 DM Serif Display，正文 Fira Sans
- 顶栏 48px（kicker + serif 路由名 + ⌘K 搜索）+ 深色侧栏 220/56
- 无大阴影、无渐变、无插画、无 emoji；hairline `1px #e6e3df` 当唯一分隔语言

## 方向 3 · "Bento Workbench"（便当盒台面）

```text
┌── 入口：bento mosaic ─────────────────────┐
│  ┌─ BOOMER 帮我拍（2×2 大）─┬─ 视频(1×1)─┐│
│  │  serif 标 + 说明 + CTA   ├─ 图片(1×1)─┤│
│  │                          ├─ 文案(1×1)─┤│
│  ├──────────────────────────┴────────────┤│
│  │ 今日待办（2×1 长）│ 用量(1×1)│历史(1×1)││
│  └───────────────────┴──────────┴────────┘│
└────────────────────────────────────────────┘

┌── 步骤：5 个 step 是 5 个不同尺寸 tile ────┐
│  12 栏 grid，按重要度分配大小：             │
│  step04 选图九宫格 = 2×2 大格               │
│  step05 生成设置  = 2×1 长格                │
│  step01/02/03    = 各 1×1 小格              │
│  顺序按视觉重量铺，不按编号 1→5             │
└─────────────────────────────────────────────┘

┌── 结果：4 种 tile 一面铺开 ────────────────┐
│ ┌─ 视频预览 2×2 ──┬─ 脚本 1×2 长 ─┐         │
│ │                 │ 5 镜逐行       │         │
│ ├─────────────────┼────────────────┤         │
│ │ 进度 1×1 │ 操作 1×1 │ 元数据 1×1 │         │
│ └──────────┴──────────┴────────────┘         │
└──────────────────────────────────────────────┘
```
- 优点：现代、节奏感强、每一块独立有呼吸
- 代价：信息分布需要训练眼睛、不如三栏紧凑
